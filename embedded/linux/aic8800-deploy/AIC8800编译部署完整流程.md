# AIC8800 USB WiFi 驱动交叉编译完整流程文档

## 1. 项目背景

### 1.1 目标

为 ARM64 (aarch64) 架构的 JelinaOS 系统编译 AIC8800 USB WiFi 驱动，使其能够识别并使用 Aicsemi AIC8800D80 芯片的 USB 无线网卡。

### 1.2 硬件信息

| 项目 | 详情 |
|---|---|
| USB VID:PID (存储模式) | `a69c:5721` |
| USB VID:PID (WiFi 模式) | `a69c:8D80` |
| 芯片厂商 | AIC / Aicsemi |
| 芯片型号 | AIC8800 / AIC8800D80 系列 |
| 目标架构 | ARM64 (aarch64) |
| 目标内核版本 | Linux 6.6.63 |

### 1.3 关键发现

- **Linux 6.6.63 主线内核中无 AIC8800 驱动**，必须使用外部 (out-of-tree) 驱动源码。
- 驱动源码仓库中**缺少 PID `0x8D80` 的支持**，需要手动修补后编译。

## 3. 驱动源码获取与修补

### 3.1 克隆驱动源码

选用 [Wolfdv1/aic8800](https://github.com/Wolfdv1/aic8800) 仓库，该分支针对 Debian 12 和较旧内核 (6.1/6.6) 做了适配：

```bash
cd /home/sa/Lab/arm_linux/arm_debian/
git clone https://github.com/Wolfdv1/aic8800.git aic8800-driver
```

**仓库信息：**

| 项目 | 详情 |
|---|---|
| Fork 来源 | `lynxlikenation/aic8800` |
| 适配环境 | Debian 12 (Bookworm), 内核 6.1.0-28 |
| 许可证 | 沿用原始代码 |
| 模块版本 | aic8800_fdrv v6.4.3.0 |

### 3.2 修补 USB PID 支持

原始驱动支持以下 WiFi 模式 PID：
- `0x8800` (AIC8800)
- `0x8801` (AIC8801)
- `0x88DC` (AIC8800DC)
- `0x88DD` (AIC8800DW)
- `0x88DF` (AIC8800FC)

**缺少 `0x8D80` (AIC8800D80)**，即本设备从存储模式切换后的 WiFi PID。

#### 修补 1：添加 PID 宏定义

**文件：** `drivers/aic8800/aic8800_fdrv/aicwf_usb.h`

```diff
+#define USB_PRODUCT_ID_AIC8800D80          0x8d80
 #define USB_PRODUCT_ID_AIC8800FC            0x88df
```

#### 修补 2：添加 USB 设备匹配表项

**文件：** `drivers/aic8800/aic8800_fdrv/aicwf_usb.c`

在 USB 设备 ID 表中插入：
```diff
 {USB_DEVICE(USB_VENDOR_ID_AIC, USB_PRODUCT_ID_AIC8800DW)},
+{USB_DEVICE(USB_VENDOR_ID_AIC, USB_PRODUCT_ID_AIC8800D80)},
 {USB_DEVICE(USB_VENDOR_ID_AIC_V2, USB_PRODUCT_ID_AIC8800FC)},
```

#### 修补 3：添加芯片型号匹配逻辑

**文件：** `drivers/aic8800/aic8800_fdrv/aicwf_usb.c`

在 `aicwf_usb_chipmatch()` 函数中插入：
```c
}else if(pid == USB_PRODUCT_ID_AIC8800D80){
    usb_dev->chipid = PRODUCT_ID_AIC8800D80;
    AICWFDBG(LOGINFO, "%s USE AIC8800D80\r\n", __func__);
    return 0;
```

> **说明：** `PRODUCT_ID_AIC8800D80` 枚举值已在 `aicwf_usb.h` 中定义但未被使用，本次修补将其激活。

## 4. 编译过程

### 4.1 准备内核构建环境

在编译外部模块之前，需要先生成内核头文件和构建脚本：

```bash
cd /home/sa/Lab/arm_linux/arm_debian/kernel/linux-6.6.63
CONFIG_SHELL=bash make ARCH=arm64 CROSS_COMPILE=aarch64-linux-gnu- prepare
```

| 参数 | 说明 |
|---|---|
| `CONFIG_SHELL=bash` | 强制使用 bash（dash 会导致 `test: -lt: unexpected operator` 错误） |
| `ARCH=arm64` | 目标架构 ARM64 |
| `CROSS_COMPILE=aarch64-linux-gnu-` | 交叉编译器前缀 |
| `prepare` | 生成 include/config、头文件、scripts 等 |

**输出：**
```
CALL    scripts/checksyscalls.sh
```

### 4.2 编译 AIC8800 驱动模块

```bash
cd /home/sa/Lab/arm_linux/arm_debian/aic8800-driver/drivers/aic8800
CONFIG_SHELL=bash make \
  KDIR=/home/sa/Lab/arm_linux/arm_debian/kernel/linux-6.6.63 \
  ARCH=arm64 \
  CROSS_COMPILE=aarch64-linux-gnu- \
  KVER=6.6.63 \
  KBUILD_MODPOST_WARN=1 \
  modules
```

| 参数 | 说明 |
|---|---|
| `KDIR=...` | 指向目标内核源码目录（覆盖默认的 `/lib/modules/...`） |
| `KBUILD_MODPOST_WARN=1` | 将 modpost 未定义符号错误降级为警告（原因见下方） |

### 4.3 关于 KBUILD_MODPOST_WARN 的说明

由于内核源码只执行了 `make prepare` 而未完整编译，没有生成 `Module.symvers` 文件。modpost 阶段无法验证模块使用的内核符号，导致大量 `undefined!` 错误。

**这些未定义符号都是标准内核 API**（如 `usb_alloc_urb`、`skb_put`、`snprintf` 等），在目标系统加载模块时会由运行中的内核自动解析，不影响实际使用。

设置 `KBUILD_MODPOST_WARN=1` 将这些错误转为警告，允许生成 .ko 文件。

## 7. 目标设备部署流程

### 7.1 传输到目标设备

```bash
scp aic8800-deploy.tar.gz root@<target_ip>:/tmp/
```

### 7.2 安装

```bash
# 在目标 ARM64 设备上执行
tar xzf /tmp/aic8800-deploy.tar.gz -C /tmp/
cd /tmp/aic8800-deploy/scripts/
chmod +x install.sh
sudo ./install.sh
```

`install.sh` 自动执行以下操作：
1. 复制固件到 `/lib/firmware/aic8800DC/`
2. 复制 .ko 文件到 `/lib/modules/$(uname -r)/kernel/drivers/net/wireless/aic8800/`
3. 运行 `depmod -a`
4. 安装 udev 规则到 `/etc/udev/rules.d/`
5. 加载 `aic_load_fw` 和 `aic8800_fdrv` 模块

### 7.3 USB 模式切换

设备首次插入时处于存储模式 (`a69c:5721`)，需要切换到 WiFi 模式 (`a69c:8D80`)：

```bash
# 方式 1: 自动 (udev 规则)
# 插入设备，udev 规则自动执行 eject

# 方式 2: 手动
sudo usb_modeswitch -KQ -v 0a69c -p 5721
```

### 7.4 功能验证

```bash
# 1. 确认设备已切换到 WiFi 模式
lsusb | grep a69c
# 预期输出: ... a69c:8d80 ...

# 2. 确认驱动已加载
lsmod | grep aic
# 预期输出: aic8800_fdrv, aic_load_fw

# 3. 确认无线网卡出现
iwconfig
# 预期输出: wlan0 接口

# 4. 扫描 WiFi 网络
sudo iw dev wlan0 scan | grep SSID

# 5. 连接 WiFi
sudo nmcli device wifi connect "SSID" password "PASSWORD"
```

## 8. 已知问题与解决方案

| 问题 | 原因 | 解决方案 |
|---|---|---|
| `make: test: -lt: unexpected operator` | `/bin/sh` 指向 dash | 使用 `CONFIG_SHELL=bash make ...` |
| `Module.symvers is missing` | 内核源码未完整编译 | 使用 `KBUILD_MODPOST_WARN=1` |
| 插入后只有存储设备，无 WiFi | 设备处于 MSC 模式 | 执行 `usb_modeswitch -KQ -v 0a69c -p 5721` |
| 驱动加载但固件失败 | 固件路径不正确 | 确认固件在 `/lib/firmware/aic8800DC/` |
| `rfkill` 阻止无线 | 软件开关已关闭 | 执行 `rfkill unblock all` |
