# 嵌入式高性能硬件钱包架构设计文档

## 1. 系统目标

- 高性能、安全的硬件钱包，适合嵌入式系统部署。
- 支持分布式备份与恢复。
- 网络校验功能，可与区块链或远程服务器进行安全通信。
- C++20 实现，充分利用多线程和性能优化技术。
- 最小化外部依赖，保证独立运行和安全。

## 3. 关键模块设计

### 3.1 私钥管理 (WalletCore)
- 使用 ECC（如 secp256k1）生成私钥和公钥。
- 私钥存储加密，使用 AES-GCM 或 ChaCha20-Poly1305。
- 内存访问时敏感数据使用锁定内存 (mprotect / MEM_LOCK) 避免交换。
- 支持助记词生成 (BIP39) 与恢复。

### 3.2 交易管理 (TransactionManager)
- 构造交易数据结构，序列化为网络标准格式。
- 离线签名，签名操作在安全执行上下文中进行。
- 多线程验证交易输入输出，确保性能。

### 3.3 分布式备份 (BackupManager)
- 多副本存储，可在 SD 卡、USB 或远程加密节点备份。
- 使用分片 + Shamir 秘密分享算法增强安全性。
- 支持增量备份和恢复。

### 3.4 网络管理 (NetworkManager)
- 支持与区块链节点或远程校验服务器通信。
- 异步网络任务，避免阻塞交易签名。
- 安全通信：TLS + ECC 双向认证。
- 可选择验证节点可信性，确保交易有效性。

### 3.5 安全模块 (SecurityManager)
- 隔离执行：关键算法在安全区 (Secure Enclave / TrustZone) 执行。
- 硬件 RNG 生成随机数。
- 抗侧信道攻击：防止电磁泄漏、时间分析。
- 使用硬件安全模块 (HSM) 或 TPM 提高安全性。

### 3.6 多线程与性能优化
- ThreadPool 管理网络、备份、签名、验证任务。
- RingBuffer + MemoryPool 处理临时数据，减少动态分配开销。
- 异步事件驱动：UI 线程与核心逻辑分离，保证响应性。

## 4. 构建与工程结构

```
embedded_hardware_wallet/
├── src/
│   ├── core/             # WalletCore、私钥管理
│   ├── transaction/      # 交易管理
│   ├── backup/           # 分布式备份
│   ├── network/          # 网络管理
│   ├── security/         # 安全模块
│   ├── ui/               # CLI / OLED / Touch UI
│   ├── hw/               # 硬件抽象层
│   └── main.cpp
├── include/              # 公共头文件
├── crypto/               # 加密库或封装
├── cmake/                # CMake 配置
├── tests/                # 单元测试
└── resources/            # 配置文件 / 助记词字典
```

- 使用 CMake 管理跨平台编译。
- 支持单元测试和静态分析工具 (clang-tidy, cppcheck)。
- 模块化设计便于后续功能扩展。

## 5. 安全与性能建议

- 确保所有敏感操作在受控线程或安全区执行。
- 使用硬件加速的加密算法和随机数生成器。
- UI 与核心逻辑完全分离，避免阻塞签名或备份任务。
- 定期性能统计：交易签名耗时、网络延迟、备份速度。
- 异常处理和日志记录在不暴露敏感信息的前提下进行。
- 分布式备份时采用端到端加密，保证密钥安全。
